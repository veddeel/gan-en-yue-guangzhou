# 丽兹行广州感恩连接行动包 · GitHub Pages 发布包

目标仓库：`veddeel/gan-en-yue-guangzhou`。目标主链接：`https://veddeel.github.io/gan-en-yue-guangzhou/`。该链接仅在仓库创建、Pages 发布成功后有效。

`public/` 是完整静态页面与图片，`.github/workflows/pages.yml` 会在 `main` 分支更新时发布同一固定链接。二维码文件 `public/action-pack-qr.png` 已指向目标主链接。

“我想要”和反馈表单仍调用原有 Sites 记录接口；后台入口仍在原有 Sites 域名。接口已增加 GitHub Pages 来源许可。由于后台域名在部分中国内地网络可能无法连接，静态礼物库可打开不等于表单一定能提交。上线后需从无需代理的网络实际测试这两项。

发布前核对 GitHub 授权账号为 `veddeel`。不要把数据库密码、GitHub token 或任何 service_role 密钥放进 `public/`。
